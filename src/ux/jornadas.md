## Jornada: Jogar (entrada rápida)
- Entrada: usuário abre o jogo -> seleciona "Jogar" -> escolhe dificuldade -> joga até acertar -> salva resultado (opcional) -> volta ao menu.
- Pontos de decisão: salvar histórico? jogar novamente?
- Tempo estimado: 1–5 minutos.

## Jornada: Ver histórico
- Entrada: menu principal -> opção "Ver historico" -> listar partidas -> selecionar partida para detalhes (se implementado) -> voltar.
- Pontos de fricção: histórico muito extenso sem paginação.

## Jornada: Consultar estatísticas
- Entrada: menu -> estatísticas -> mostrar média de tentativas, vitórias/derrotas, melhor pontuação.

### Observações
- Cada jornada deve terminar com uma ação clara: voltar ao menu, sair ou reiniciar.
