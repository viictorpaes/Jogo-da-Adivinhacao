As personas foram construídas a partir dos perfis de usuários que interagem com o **CesarNumber** — representando diferentes níveis de experiência, objetivos e frustrações.

---

## 1. Ana — A Novata

<img src="https://img.shields.io/badge/Perfil-Iniciante-22c55e?style=flat-square" height="18"/> <img src="https://img.shields.io/badge/Idade-18–30-111827?style=flat-square" height="18"/> <img src="https://img.shields.io/badge/Terminal-Primeira_vez-111827?style=flat-square&logo=gnubash&logoColor=white" height="18"/>

> *"Quero entender as regras rápido e só me divertir."*

| Atributo | Detalhe |
| :--- | :--- |
| **Contexto** | Joga em terminal pela primeira vez; procura algo rápido e divertido |
| **Objetivos** | Entender as regras rapidamente, receber feedback claro e encorajador |
| **Frustrações** | Mensagens técnicas confusas, entradas inválidas sem explicação |
| **Prioridade UX** | Fluxo simples, linguagem amigável, erros sempre explicados |

---

## 2. Bruno — O Jogador Casual

<img src="https://img.shields.io/badge/Perfil-Casual-f59e0b?style=flat-square" height="18"/> <img src="https://img.shields.io/badge/Idade-25–45-111827?style=flat-square" height="18"/> <img src="https://img.shields.io/badge/Sessões-Curtas-111827?style=flat-square&logo=clockify&logoColor=white" height="18"/>

> *"Jogo nas pausas — quero desafio moderado e reiniciar rápido."*

| Atributo | Detalhe |
| :--- | :--- |
| **Contexto** | Joga em momentos de pausa; espera responsividade e reinício ágil |
| **Objetivos** | Desafio moderado, histórico de resultados visível, ciclo de jogo curto |
| **Frustrações** | Prompts desnecessários, tempo de carregamento, interface lenta |
| **Prioridade UX** | Ciclo rápido de jogo, opção de reiniciar sempre acessível |

---

## 3. Carla — A Entusiasta Competitiva

<img src="https://img.shields.io/badge/Perfil-Competitivo-ef4444?style=flat-square" height="18"/> <img src="https://img.shields.io/badge/Idade-30–55-111827?style=flat-square" height="18"/> <img src="https://img.shields.io/badge/Foco-Ranking_&_Stats-111827?style=flat-square&logo=databricks&logoColor=FF3621" height="18"/>

> *"Jogo para melhorar meu score e comparar com sessões anteriores."*

| Atributo | Detalhe |
| :--- | :--- |
| **Contexto** | Joga para evoluir; se interessa por estatísticas e comparação de desempenho |
| **Objetivos** | Registrar histórico, ver métricas, comparar tentativas entre partidas |
| **Frustrações** | Falta de persistência de resultados, pontuação ambígua |
| **Prioridade UX** | Histórico e métricas exportáveis, ranking confiável e acessível |

---

## Mapa de Prioridades UX por Persona

| Necessidade | Ana 🟢 | Bruno 🟡 | Carla 🔴 |
| :--- | :---: | :---: | :---: |
| Mensagens claras e acessíveis | ✅ Alta | ✅ Alta | ⬜ Baixa |
| Ciclo de jogo rápido | ✅ Alta | ✅ Alta | ✅ Alta |
| Histórico de partidas | ⬜ Baixa | 🔸 Média | ✅ Alta |
| Ranking e estatísticas | ⬜ Baixa | 🔸 Média | ✅ Alta |
| Múltiplos níveis de dificuldade | 🔸 Média | ✅ Alta | ✅ Alta |
| Exportação de dados (CSV) | ⬜ Baixa | ⬜ Baixa | ✅ Alta |

> [!NOTE]
> As personas guiam decisões de design e priorização de features. Sempre que uma nova funcionalidade for considerada, avalie o impacto em cada perfil antes de implementar.
