## 🗂️ Categorias de Jogo

Para o dia do evento, os jogos são divididos em **duas filas/estações distintas**:

| Categoria | Jogos Disponíveis | Dinâmica |
| :---: | :--- | :--- |
| ⚔️ **Modo Arena** | Adivinhação 1v1 · Jogo da Memória 1v1 | Confronto direto — dois entram, um vence |
| 🧩 **Modo Jornada** | Adivinhação Solo · Memória Solo · Hierarquia de Comandos · Protocolo Lógico | Risco vs. Recompensa — desafio progressivo |

## ⚔️ Modo Arena (1v1)

<img src="https://img.shields.io/badge/Adivinha%C3%A7%C3%A3o%201v1-111827?style=flat-square&logo=gamepad&logoColor=4CAF50" height="18"/> <img src="https://img.shields.io/badge/Mem%C3%B3ria%201v1-111827?style=flat-square&logo=gamepad&logoColor=00BCD4" height="18"/>

> Confronto direto e rápido. **Dois jogam, apenas um sai vitorioso.**

| Regra | Detalhe |
| :--- | :--- |
| 🏆 **Regra de Ouro** | O prêmio é **instantâneo** — ganhou, levou |
| 🚫 **Empate** | Empates **não** geram prêmio |
| 📊 **Ranking** | **Ambos os jogadores** se registram — vencedor e perdedor entram no ranking geral do evento |
| 🔄 **Rotatividade** | Após o fim da partida, os jogadores **liberam a máquina** imediatamente |

> [!IMPORTANT]
> No Modo Arena o prêmio físico é entregido **na hora** somente ao vencedor, sem escolhas adicionais. Porém, **os dois participantes digitam seus nomes** para o ranking antes de liberar a estação — cada partida conta pontos para ambos.

### ⚖️ Mecânica de Risco vs. Recompensa

#### Critérios de Resultado

| Resultado | Condição |
| :---: | :--- |
| ✅ **Vitória** — Ganha Recompensa | Acertou **mais do que errou** dentro do limite de tempo |
| ❌ **Derrota** — Sem Recompensa | Tempo esgotado **OU** número de erros maior que o de acertos |

### 🎯 A Decisão: Seguir ou Parar?

Ao vencer uma fase/modo, o jogador se depara com uma escolha na tela:

```
┌─────────────────────────────────────────────────────────┐
│             🏆  PARABÉNS — VOCÊ VENCEU!                 │
│                                                         │
│   [1] 🎁  Retirar Prêmio e Pontuar                      │
│   [2] 🎲  Dobrar ou Nada  (continuar jogando)           │
└─────────────────────────────────────────────────────────┘
```

| Opção | O que acontece |
| :--- | :--- |
| 🎁 **Retirar Prêmio e Pontuar** | Digita o nome para o ranking · recebe o voucher/brinde · libera a máquina · pode voltar ao fim da fila para outro modo |
| 🎲 **Dobrar ou Nada** | Abdica do prêmio físico atual · tenta pontuação maior em um modo mais difícil · se **vencer**: novo prêmio + pontuação maior · se **perder**: sem prêmio físico, mas os pontos acumulados até a derrota ainda entram no ranking |

> [!NOTE]
> Ao escolher **Dobrar ou Nada**, o jogador permanece na máquina e nenhum prêmio físico é garantido. Os pontos acumulados até o momento da derrota são sempre salvos no ranking.

> [!TIP]
> **Estratégia:** Modo Fácil → Médio → Difícil encadeados no "Dobrar ou Nada" multiplicam a pontuação — mas um único erro encerra a sequência de prêmios!

## 📜 Regras Oficiais de Premiação

> Para exibição nos **telões e totens** próximos às estações de jogo.

| # | Regra | Detalhe |
| :---: | :--- | :--- |
| 1 | ⚔️ **Modos 1v1** | Vitória garante prêmio imediato · empates **não** geram prêmios |
| 2 | 🧩 **Modos Solo** | Para ganhar: vencer o relógio **E** ter mais acertos do que erros |
| 3 | 🎁 **Limite de Brindes** | Cada participante pode ganhar no máximo **5 prêmios** por dia |
| 4 | 🔄 **Abandono de Fila** | Escolheu retirar o prêmio → **libere a máquina** · escolheu continuar → permanece na estação |

> [!IMPORTANT]
> O limite de prêmios por participante (**X**) deve ser definido pela organização antes do evento e configurado na tela de operador.

```
Chegou na estação
        │
        ▼
┌───────────────┐     ┌───────────────────┐
│  Modo Arena   │     │  Modo Jornada     │
│    (1v1)      │     │    (Solo)         │
└──────┬────────┘     └────────┬──────────┘
       │                       │
  Joga 1 partida          Joga modo escolhido
       │                       │
  Venceu? ──Não──► Sem prêmio  Venceu? ──Não──► Sem prêmio
       │                       │                (pts salvos)
      Sim                     Sim
       │                       │
  Prêmio imediato    ┌─────────▼──────────┐
  + registro         │  Retirar ou Dobrar? │
  ranking            └────────┬───────────┘
       │              Retirar │  Dobrar
       │                      │     │
       │              Prêmio  │  Próximo modo
       │              + rank  │  mais difícil
       ▼                      ▼     ▼
  Libera máquina       Libera    Permanece
                       máquina   na máquina
```
